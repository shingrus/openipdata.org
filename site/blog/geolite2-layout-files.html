title: The database files now use the GeoLite2 layout date: 2026-11-21 summary: openipdata-org-ip2geo.mmdb and openipdata-org-ip2asn.mmdb are published in the GeoLite2-City and GeoLite2-ASN record layout. ---

The two MMDB files we publish now use the record layout of GeoLite2-City and GeoLite2-ASN. A program that reads GeoLite2 with MaxMind's Python reader, or with any plain MMDB reader, can read ours by changing the file path.

Files

  • openipdata-org-ip2geo.mmdb: country, city, coordinates. database_type is OpenIPData-City.
  • openipdata-org-ip2asn.mmdb: the network of an address. database_type is OpenIPData-ASN (compat=GeoLite2-ASN).
  • asn-openipdata.sqlite3: networks, organizations and prefixes.

Fields

The city file has country.iso_code, country.names.en, city.names.en, location.latitude and location.longitude, plus continent, location.time_zone and country.is_in_european_union. A field is absent when we do not know it. There is one extra top-level key, city_source, which names the source of the city. The ASN file has autonomous_system_number and autonomous_system_organization.

Python

import geoip2.database
reader = geoip2.database.Reader("openipdata-org-ip2geo.mmdb")
r = reader.city("8.8.8.8")
r.country.iso_code, r.city.names["en"]

Go

The Go library geoip2-golang accepts only a fixed list of database types, so it refuses both files. The plain maxminddb-golang reader works: define a struct with the fields you need and look up into it.

Old files

The earlier flat files, ip2geo-openipdata.mmdb and ip2asn-openipdata.mmdb, stay on the release for about 60 days and are no longer updated.

Get the files and the field list on the download page. The data is CC0; the GeoNames ids, time zones and coordinates are credited to GeoNames (CC BY 4.0).
