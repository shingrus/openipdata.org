title: Bulk IP lookup and the JSON list API date: 2026-11-17 summary: Look up to 1000 addresses at once on a web page or with curl, and get a table, a CSV file or a JSON array back. ---

The page Bulk IP lookup takes a text with up to 1000 IP addresses. Paste a log or a list; the addresses are found in any text. You get a table of country, city, coordinates and network, and a button that downloads it as CSV.

Privacy

The form is a POST, so a pasted list never reaches a URL, a log or the browser history. Nothing you paste or get back is stored.

API

The same lookups work from the command line. Up to 100 addresses in the URL, separated by commas:

curl https://openipdata.org/json/1.1.1.1,8.8.8.8

Up to 1000 addresses in the body, one per line (or a JSON array of strings, body up to 64 KB):

curl --data-binary @ips.txt https://openipdata.org/json

Both answer a JSON array with one entry per item, in the order you sent them, duplicates included. An entry is the same object as /json/<ip>. An address that cannot be looked up gives an error entry instead:

{"ip": "10.0.0.1", "error": "not a public address"}
{"input": "abc", "error": "not an IP address"}

A single address without a comma keeps the single-object answer. A field is absent when it is unknown.

CSV

On the page, the button Download CSV gives the same rows as ip-geolocation.csv. Text values that start with =, +, - or @ get a leading quote, so a spreadsheet does not read them as a formula.
