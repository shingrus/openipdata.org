# Browser and OS icons

Drawn inline on the visitor's own page, in the Browser row: one browser logo and one OS logo.

- `chrome.svg`, `firefox.svg`, `safari.svg`, `edge.svg`, `opera.svg`, `brave.svg`, `samsung-internet.svg`, `vivaldi.svg`: the colour logos of [alrra/browser-logos](https://github.com/alrra/browser-logos) 70.4.0 (`src/<name>/<name>.svg`), MIT licence, text in `LICENSE-browser-logos.txt`.
- `os-apple.svg`, `os-android.svg`, `os-linux.svg`, `os-ubuntu.svg`: [Simple Icons](https://simpleicons.org) 13.21.0 (`icons/<name>.svg`), CC0 1.0. Filled at render time with the brand colour (Apple: the text colour).
- Shrunk once by hand (path numbers only, same look): `firefox.svg` scaled by 1/200 (viewBox 0 0 257.5 257.5) with whole-number coordinates, 7,508 to 5,881 bytes; `os-linux.svg` rounded to one decimal, 5,463 to 3,513 bytes. Arc rotations and flags unchanged.
- Windows: four squares drawn in the code (Simple Icons no longer has Microsoft logos).

The logos are trademarks of their owners; they only name the visitor's browser and system.
